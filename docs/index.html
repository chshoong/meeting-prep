작업하면서 남긴 기록으로
미팅 자료가 만들어져요

Claude와 연구·프로젝트를 하면서 로그를 남기고, 교수님 미팅이 끝나면 피드백을 기록하세요. 다음 미팅 전에 그 기록을 근거로 PPT·PDF 자료와 웹 보고서를 만들어 줍니다.

PowerPoint에서 바로 고칠 수 있는 PPTXPDF인터넷 없이 열리는 웹 보고서명령어 암기 없음
왜 쓰나한 사이클만들어지는 것설치처음 시작하기사용법파일 위치자주 묻는 것
Why

미팅 전날 밤, 지난 2주를 되짚느라 시간을 쓰지 않게

결과는 채팅 곳곳에, 교수님 말씀은 노션 메모나 녹음에 흩어져 있어요. meeting-prep은 이걸 트랙(논문 하나, 프로젝트 하나)마다 한곳에 모아 두고, 미팅 자료를 만들 때 근거로 씁니다.

"이번 주에 뭘 했더라?"

작업할 때마다 로그가 쌓여요. 결과가 나오면 Claude가 먼저 "여기까지 기록해둘까요?"라고 물어요.

"교수님이 지난번에 뭐라고 하셨지?"

미팅 메모나 녹음 텍스트를 붙여 넣으면 할 일·지적·아이디어로 정리해요.

"슬라이드 디자인할 시간이 없어"

차트·표·피드백 반영 현황이 들어간 연구자용 슬라이드를 기록에서 바로 만들어요.

How it works

미팅 한 번이 한 사이클

사이클은 미팅 날짜로 묶여요. 미팅이 끝나면 다음 사이클이 자동으로 열리고, 지난 피드백의 할 일이 새 로그 맨 위에 올라와요.

  1. 작업하며 기록

    평소처럼 Claude와 분석·코딩을 해요. 중요한 결과가 나오면 기록이 남아요.

    "기록해줘"

  2. 미팅 자료 만들기

    목차를 먼저 보여주고 확인받은 뒤 슬라이드를 만들어요. 웹 보고서도 같이 갱신할 수 있어요.

    "이번 주 미팅 자료 만들어줘"

  3. 교수님 미팅

    PPT로 발표하거나 웹 보고서를 화면 공유해요. 조건을 바꿔 가며 결과를 바로 보여줄 수 있어요.

  4. 피드백 정리

    메모나 녹음 텍스트를 붙여 넣으면 할 일 목록이 되고, 다음 사이클이 시작돼요.

    "미팅 끝났어, 피드백 정리해줘"

다음 미팅 자료에는 "지난 피드백 반영 현황" 슬라이드가 자동으로 들어가요. 할 일마다 완료·진행 중·미착수로 표시돼요.

미팅 슬라이드

제목이 곧 결론인 연구 발표 형식이에요. 슬라이드 종류 10가지(표지, 간지, 차트, 수치 카드, 단계, 그림, 표, 피드백 현황, 전후 비교, 글머리표) 중에서 내용에 맞게 골라요.

  • 단순 비교 차트는 PowerPoint 기본 차트라서 값과 색을 바로 고칠 수 있어요.
  • 모든 글자는 텍스트 상자라 편집 가능해요.
  • 만든 뒤 Claude가 슬라이드 이미지를 직접 보고 넘치거나 깨진 곳을 고쳐요.

웹 보고서

트랙마다 계속 쌓이는 대화형 보고서예요. 파일 하나라서 메일로 보내도 인터넷 없이 열려요.

  • 필터로 조건을 바꾸면 차트와 표가 따라 바뀌어요.
  • 비교 패널에서 두 조건을 골라 평균 ± 표준편차와 차이를 봐요. 더 나은 쪽은 초록색으로 표시돼요.
  • 표는 머리글을 눌러 정렬하고 검색할 수 있어요.
  • 미팅용 강조판에는 "이번 미팅" 탭과 NEW·변경 표시가 붙어요.
  • 수치는 CSV 원본 그대로 쓰고, 데이터 출처(경로·행 수)를 보고서 안에 남겨요.
Install

설치는 한 번만

Claude Code 데스크톱 앱 또는 터미널 Node.js 20 이상 Edge 또는 Chrome (PDF·미리보기용, 윈도우는 Edge 기본 설치)

1터미널에서 두 줄 실행

데스크톱 앱을 쓴다면 앱 안의 터미널이나 PowerShell에서 실행하면 돼요.

claude plugin marketplace add chshoong/meeting-prep
claude plugin install meeting-prep@meeting-prep-local

2새 채팅 열기

플러그인은 채팅을 시작할 때 불러와요. 설치한 뒤에는 꼭 새 채팅을 열고, 아래 "처음 시작하기"를 따라 하세요.

3새 버전 받기

업데이트가 나오면 두 줄을 실행하고 새 채팅을 열어요.

claude plugin marketplace update meeting-prep-local
claude plugin update meeting-prep@meeting-prep-local
First steps

처음 시작하기

작업하던 폴더(논문 코드나 프로젝트 폴더)로 새 채팅을 열고 아래 순서대로 말해 보세요. 1번만 하면 바로 쓸 수 있고, 2·3번은 해두면 첫 미팅 자료가 훨씬 좋아져요.

  1. 이 폴더를 트랙으로 등록

    필수

    "이 폴더를 미팅 트랙으로 등록해줘"

    Claude가 이름(기본은 폴더 이름)과 종류(연구 / 프로젝트)를 한 번 물어요. 이때 허브 폴더와 필요한 패키지도 자동으로 준비돼요. 논문과 프로젝트를 같이 하면 폴더마다 한 번씩 등록하세요.

  2. 참고할 논문·노트 연결

    선택

    "내 논문 PDF 폴더 C:\…\papers도 참고해줘"

    미팅 자료에 선행연구 근거를 달 때 써요. llm-wiki 같은 노트 폴더도 돼요. 이 폴더는 읽기만 하고 고치지 않아요. 없으면 건너뛰세요.

  3. 지난 미팅 피드백 넣기

    추천

    "지난 미팅 피드백 정리해줘" + 노션 메모나 녹음 텍스트 붙여넣기

    교수님 말씀이 할 일 목록이 돼요. 다음 미팅 자료에 "지난 피드백 반영 현황"이 자동으로 들어가고, 작업을 기록할 때 어떤 할 일을 했는지도 같이 남아요.

  4. 평소처럼 작업

    이제 분석하고 코딩하면 돼요. 결과가 나오면 Claude가 "💾 여기까지 기록해둘까요?"라고 먼저 물어요. 직접 "기록해줘"라고 해도 돼요. 미팅 전에 "이번 주 미팅 자료 만들어줘"라고 하면 끝이에요.

Usage

그냥 이렇게 말하면 돼요

명령어를 외울 필요 없어요. 작업하던 폴더에서 Claude에게 평소 말투로 말하면 알맞은 기능이 실행돼요.

하고 싶은 것이렇게 말하기무슨 일이 일어나나
작업 기록"기록해줘"이 채팅에서 마지막 기록 이후 한 일을 요약해 트랙 로그에 남겨요. 방금 남긴 기록은 "고쳐줘"로 수정해요.
미팅 후 정리"미팅 끝났어, 피드백 정리해줘"붙여 넣은 메모나 녹음 텍스트를 할 일·지적·아이디어로 나누고, 다음 사이클을 열어요.
미팅 자료"이번 주 미팅 자료 만들어줘"주제와 강조할 점을 묻고, 목차를 확인받은 뒤 PPTX·PDF를 만들어요.
웹 보고서"보고서 업데이트해줘"트랙의 웹 보고서에 새 결과를 섹션으로 추가하고 탭별 화면을 확인해요.
미팅 날짜"다음 미팅은 10월 14일이야"열린 사이클에 날짜를 붙여요. 자료 표지와 강조판에 쓰여요.
자료 연결"이 폴더도 이 트랙에 포함해줘", "내 llm-wiki도 참고해줘"트랙에 작업 폴더를 더하거나, 논문 노트·PDF 폴더를 지식 소스로 등록해요.

문헌 근거와 방법·결과 흐름이 중심이에요. 웹 보고서 기본 탭은 목표 · 데이터 · 방법 · 결과 · 해석.

Files

기록은 모두 내 컴퓨터의 마크다운 파일

허브 폴더(기본 ~/meeting-hub)에 트랙별로 쌓여요. 직접 열어서 고쳐도 되고, 폴더째 백업하면 돼요.

~/meeting-hub/
  hub.md                       지식 소스 목록 (llm-wiki, 논문 PDF 폴더)
  library/                     지식 소스가 없을 때 쌓이는 논문 노트
  tracks/research|project/<트랙>/
    track.md                   이 트랙의 작업 폴더
    report/report.html         웹 보고서 (누적판)
    cycles/<미팅 날짜>/
      feedback.md              교수님 피드백 · 할 일
      log.md                   그 사이클의 작업 기록
      deck/deck.pptx, deck.pdf 미팅 자료
    cycles/next/               날짜가 아직 없는 진행 중 사이클
FAQ

자주 묻는 것

Claude가 명령 실행 허락을 계속 물어봐요

처음 몇 번은 node … 실행 허락을 물어요. 허락할 때 "항상 허용"을 고르면 다음부터는 묻지 않아요.

기록 제안이 너무 자주 / 드물게 와요

기본은 마지막 기록 후 90분이 지났을 때예요. ~/.meeting-prep/config.json의 nudgeMinutes 값으로 바꿀 수 있어요. "기록 제안 간격 2시간으로 바꿔줘"라고 해도 돼요.

llm-wiki 같은 논문 정리 도구가 없어도 되나요?

돼요. 지식 소스가 없으면 Claude가 참고한 논문 노트를 허브의 library/에 자동으로 모아 가며 써요. 논문 PDF 폴더만 등록해도 됩니다.

PDF나 미리보기 이미지가 안 만들어져요

Claude Code의 샌드박스가 브라우저 실행을 막는 경우가 많아요. Claude가 "샌드박스 밖에서 다시 실행할까요?"라고 물으면 허락해 주세요. PPTX는 브라우저 없이도 만들어져요.

PowerPoint에서 글꼴이 달라 보여요

슬라이드는 Pretendard 글꼴을 기준으로 만들어요. PowerPoint에서도 같게 보려면 Pretendard를 설치하세요. PDF와 웹 보고서에는 글꼴이 들어 있어서 따로 설치할 필요가 없어요.

웹 보고서를 교수님께 보내도 되나요?

HTML 파일 하나라서 메일에 첨부하면 돼요. 인터넷 연결 없이 브라우저로 열리고, 필터·비교도 그대로 동작해요. 다만 보고서에 쓴 데이터(CSV의 필요한 열)가 파일 안에 들어 있으니 공유 범위는 확인하세요.

내 기록이 어디로 전송되나요?

허브 파일은 모두 내 컴퓨터에 저장돼요. 자료를 만들 때 Claude가 그 파일을 읽는 것은 평소 Claude Code 사용과 같아요.
